\# Causal Flask Application

A Flask-based web application developed as an academic project for causal relationship analysis from accommodation reviews.



\## Technologies

\- Python

\- Flask

\- HTML/CSS

\- Natural Language Processing



\## Project Role

\- Contributed to system development and web application implementation.

\- Worked with review data and causal relationship analysis.

\- Developed the web interface for presenting analysis results.



\## Project Structure

\- `app.py` — Flask application

\- `templates/` — HTML templates

\- `static/` — CSS and static files

\- `requirements.txt` — Python dependencies



\## Note

Large trained model files and datasets are not included in this repository because of their file size.
